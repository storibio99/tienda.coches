🚘 Descripción General

El proyecto consiste en el desarrollo del backend (API REST) y la interfaz pública/administración de un módulo e-commerce dedicado al sector automovilístico. Permite a usuarios no identificados explorar el catálogo de coches con filtros dinámicos, consultar fichas detalladas y gestionar compras o reservas, ofreciendo además un panel de administración para la gestión de categorías y productos.

✨ Características Principales

Catálogo Público de Vehículos: Navegación dinámica con paginación, ordenación y filtrado por texto o categoría (Fórmula 1, Prototipos, etc.).

Ficha Técnica Detallada: Consulta completa del vehículo (cilindrada, año, tipo de combustible, caballos de potencia, precio e imágenes).

Gestión Multilingüe: Soporte visual para cambio de idioma (Español, Inglés, Japonés).

Panel de Administración (CRUD): Creación, edición y eliminación de categorías y vehículos.

Sistema de Autenticación: Registro e inicio de sesión de usuarios con opción de recordar credenciales.

🛠️ Tecnologías Utilizadas

Backend & API REST

Lenguaje: Java 17 / 21 LTS

Framework: Spring Boot 3.x (Spring Web, Spring Data JPA)

Persistencia: Hibernate / JPA con Base de Datos Relacional (PostgreSQL / MySQL / H2)

Gestor de Dependencias: Maven / Gradle

Frontend & Vistas

Librerías / Layout: Tailwind CSS (diseño responsivo de alto contraste en tonos verdes oscuros/emerald)

Interactividad: jQuery / AJAX para consumo de endpoints REST

Plantillas: Vistas dinámicas con HTML5 y Tailwind
